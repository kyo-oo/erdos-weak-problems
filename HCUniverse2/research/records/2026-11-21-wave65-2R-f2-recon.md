## The pin's `Proj.map` chart API (verified verbatim)

* `Proj.map_preimage_basicOpen` (Functor.lean:160, simp):
  `map f hf ⁻¹ᵁ basicOpen 𝒜 s = basicOpen ℬ (f s)` — **rfl**. The preimage of
  the target's `D+(s)` chart under the embedding IS the domain's
  `D+(f s)` chart. THE restriction key.
* `Proj.awayι_comp_map` (Functor.lean:192, reassoc): for `s ∈ 𝒜 i`, `0 < i`:
  `awayι ℬ (f s) (f.2 hs) hi ≫ map f hf =
    Spec.map (CommRingCat.ofHom (Away.map f s)) ≫ awayι 𝒜 s hs hi`
  — **THE per-chart square**: on the target chart `D+(s)` the embedding is
  exactly `Spec.map` of the chart ring map `Away.map f s : Away 𝒜 s →+* Away ℬ (f s)`.
* `awayι` (Basic.lean:186) is an OPEN IMMERSION (instance, Basic.lean:193),
  `awayι = basicOpenIsoSpec.inv ≫ (basicOpen 𝒜 f).ι` by rfl (Basic.lean:191),
  `opensRange_awayι` (Basic.lean:196).
* `Away.map_mk` (HomogeneousLocalization.lean:732, simp):
  `Away.map g f (.mk 𝒜 hf n x hx) = .mk ℬ (map_mem g hf) n (g x) (map_mem g hx)`;
  `Away.mk_surjective` (l.618) every element is an `mk`.
* **NO `Away.map`-surjectivity lemma exists at the pin** — F2 must prove it
  (the sub-battle below).
* `IsZariskiLocalAtTarget.of_iSup_eq_top` + `IsClosedImmersion.spec_of_surjective`
  — both CI-green in the finite-point carrier (the corpus precedent).

Per chart `j : Fin (2 * M)`, `chart_closed` decomposes the restricted
embedding through the away-charts of BOTH schemes (the `awayι_comp_map`
square + `map_preimage_basicOpen` + the `MorphismProperty.cancel_*`

`IsClosedImmersion (Spec.map (CommRingCat.ofHom (Away.map (lineGradedQuotientHom M) (MvPolynomial.X j))))`

which closes by `IsClosedImmersion.spec_of_surjective` given the
**Away-surjectivity sub-battle**:


**THE KEY (already green in the corpus)**: the piece-level lift is EXACTLY
`mem_lineGrading` (GSTFiniteLineRing.lean:160): every element of
