UPPER SIDE f(n) ≤ C(2n−4, n−2)+1 (ES 1935, "cups and caps"):

   convex chain with strictly increasing slopes; an s-CAP dually with
   decreasing slopes.
2. LEMMA (pairs): any set of C(r+s−4, r−2)+1 points contains an r-cup or an
   s-cap. Classical proof: label each 2-subset (pair) with the maximal

   lemma (3-point orientation case split) shows the labeling is injective
   into the grid [1,r−1]×[1,s−1] along a monotone staircase — count pairs
   with the hockey-stick/binomial identity to get the C(r+s−4, r−2) bound.
