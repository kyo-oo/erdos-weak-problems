## KILL 1 — THEOREM ES-ALLN (the all-n bound; the headline)

**THEOREM ES-ALLN.** For every n >= 3: every set of C(2n-4, n-2) + 1
points in general position in the plane contains n points in convex
position. Hence f(n) <= C(2n-4, n-2) + 1 for every n >= 3.

The in-package derivation (cups/caps built from scratch — no classical
citation load-bearing anywhere):
1. **THE ROTATION LEMMA.** WLOG no two points share an x-coordinate: the
   bad directions are finitely many (<= C(m,2)); a generic rotation
   preserves general position AND convex position. Prove in-package
   (convex position is rotation-invariant: bracket signs scale by a
   positive determinant — carry with plucker_four / bracket laws).
2. **THE (a,b)-LEMMA.** Every set of >= C(a+b-4, a-2) + 1 GP points with
   distinct x-coordinates contains an a-cup or a b-cap (cup/cap =
   convex chain with all brackets one sign). Proof: double induction on
   (a,b); label each point p by the pair (L(p), R(p)) = max cup length /
   max cap length ending at p; the label set has < C(a+b-4, a-2) + 1
   possible values below (a,b), so two points share a label; the bracket
   sign between them forces one to extend the other's chain — pigeonhole
   closes the induction. Every case closed with orientation arithmetic;
   the engine verifies each induction case on exhaustive small
   configurations + random batteries.
3. **THE COMPOSITION.** f(n) <= f(n,n) <= C(2n-4, n-2) + 1 (an n-gon
   needs an n-cup or n-cap among any 2-way split — assemble precisely).
Statement: zero premises, ALL n >= 3, explicit binomial bound.
